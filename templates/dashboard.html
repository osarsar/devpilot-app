                ~/devpilot/projects/…
                
            

            
        

        

            
            
        

        

            
            
        

        

            Un terminal s'ouvre dans ce dossier ; lance tes commandes (git clone, reconstruct.sh...). Tout se cree la ou tu
            les lances. Les variables MD_ROOT suivent le dossier courant ;
            pour un autre chemin : MD_ROOT=/autre/chemin ./script.sh. Supprimer tout du PC

        
Tout ce qui est coche est supprime, dans cet ordre : terminaux, processus, conteneurs, reseaux,
            volumes, images, liens et lanceurs, puis le dossier (a la corbeille, recuperable). Docker ne passe pas par la corbeille.

        

        
Tape  pour confirmer.

Besoins de ce projet

    

    

    

        
        
    







    
Console du projet

    
Un gros projet a sa propre console (comme md_console pour MarocDefender). DevPilot la lance et l'ouvre ; ce qu'elle gere n'est pas saisi dans DevPilot.

    

        

        

    

    

        

        

    

    

        

    

    

        
        

    







    
Acces par mot de passe

    

        Avec le mot de passe du serveur, DevPilot installe la cle SSH de ce PC. Choisis aussi ton propre mot de passe :
        celui d'OVH expire, le tien permettra a un nouveau PC d'ajouter sa cle sans rien reconstruire.
        Aucun mot de passe n'est enregistre par DevPilot.
    

    

        

    
    

        

            

                

            

                

        

        

        
        
Garde-le dans ton gestionnaire de mots de passe (Bitwarden...) : DevPilot ne le garde pas.
